# Часик

Простий трекер часу для дитини: поточна справа, круг, що тане, і одна кнопка «Готово».

**Відкрити:** https://natalikazichuk.github.io/chasyk/

## Як встановити на Android

1. Відкрийте адресу вище в Chrome.
2. Меню ⋮ → «Додати на головний екран» (або «Встановити застосунок»).
3. На екрані з'явиться іконка «Часик». Далі він працює без інтернету.

Усі дані (розпорядки, зірки, історія) зберігаються лише на телефоні.

Режим дорослого: утримуйте ⚙️ угорі праворуч 3 секунди й розв'яжіть приклад.
